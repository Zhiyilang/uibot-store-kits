# UiBot Store 命令库套装（UB / BotScript）

面向 **UiBot Creator** 的「命令库」源码，可直接粘贴使用，也可一键发布到 **UB Store**（来也机器人商城）赚被动收入。
全部使用 UiBot 自带命令，**零第三方依赖、零成本**。

> ⚠️ 说明：源码由我（AI）按 UiBot 标准 BotScript 语法编写并做了逻辑自查，但**无法在 UiBot Creator 里实测**。
> 请在你本机 UiBot Creator 中按下面步骤导入跑一遍验证，再上架。命令名与 UiBot 各版本基本兼容；如个别命令名略有差异，按提示微调即可。

## 包含的命令库

### 1. `excel_toolkit/ExcelToolkit.src` —— Excel 数据清洗（RPA 最高频需求）
| 命令（子程序） | 参数 | 作用 |
|---|---|---|
| `Excel删除空行` | 文件路径, 表名 | 删除整行无任何内容的空行，返回保留行数 |
| `Excel去重行` | 文件路径, 表名, 依据列(从1起) | 按指定列删除重复行（保留首次出现） |
| `Excel合并工作表` | 文件夹路径, 表名, 输出文件 | 合并文件夹内所有 xlsx 的指定表到一个新文件 |
| `Excel按列拆分` | 文件路径, 表名, 依据列, 输出文件夹 | 按某列的值拆分成多个文件（每个值一个 xlsx） |

### 2. `file_toolkit/FileToolkit.src` —— 文件批处理
| 命令（子程序） | 参数 | 作用 |
|---|---|---|
| `文件去重` | 文件夹路径, 是否删除 | 先比大小再比内容找重复文件，返回处理数量 |
| `批量重命名` | 文件夹路径, 查找文本, 替换文本 | 批量替换文件名中的文本，返回重命名数量 |
| `导出目录树` | 文件夹路径, 输出文件 | 递归导出目录结构到 txt |

## 使用方法（3 步）

### 步骤 A：导入到 UiBot Creator
1. 打开 **UiBot Creator** → 主页「新建」→ 选择 **命令库**（不是流程）。
2. 右键左侧流程块 → 切到 **源代码视图**。
3. 把对应的 `.src` 文件**全文复制粘贴**进去，保存。
4. 切回可视化视图，应看到 4 条（或 3 条）扩展命令。

### 步骤 B：本地验证
- 准备一个测试 xlsx / 测试文件夹，拖一条命令进去填参数，点「运行」。
- 确认结果正确（如去重后行数减少、拆分文件生成正常）。

### 步骤 C：发布 + 上架 UB Store（你的动作 = 上传作品）
1. 工具栏点 **「发布库」**（新版本叫「发布至本地」），生成 `.zip` 命令库包。
2. 打开 [UB Store 创作者中心](https://www.uibot.com.cn) → 发布你的机器人/命令库。
3. 填标题、截图、定价（可设免费引流或小额收费），提交审核。
4. 审核通过后即上架，后续下载/购买即被动收入。

> 也可以把 `.zip` 直接发给同事/客户，他们用「命令中心 → 导入命令库」即可使用。
