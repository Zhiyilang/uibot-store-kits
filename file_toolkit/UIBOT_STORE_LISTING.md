## 标题
文件批处理命令库 · 重复文件清理/批量重命名/目录树导出（UiBot 零依赖）

## 副标题 / 一句话
3 个即用命令，把"找重复文件、批量改名、导出目录结构"这类机械活一键做完，全部用 UiBot 自带命令，不装任何插件。

## 详细描述
### 能帮你解决什么
下载文件夹越堆越乱、文件名要批量替换、交付前要导出目录结构给客户——
这些文件管理杂活，拖一条命令就清完，不用手动一个个点。

### 功能（3 个命令）
- `文件去重(文件夹路径, 是否删除)`：先比大小再比内容找重复文件，是否删除=True 时清理后续重复项，返回处理数量。
- `批量重命名(文件夹路径, 查找文本, 替换文本)`：批量替换文件名中的文本，返回实际重命名数量。
- `导出目录树(文件夹路径, 输出文件)`：递归导出文件夹结构到 txt（树状），方便归档/交付说明。

### 适用人群
UiBot RPA 开发者、行政/文员、需要整理大量文件与交付目录的团队。

### 使用示例（流程里拖一条命令填参数即可）
```
n = 批量重命名("D:\素材\2026", "副本", "")
TracePrint "已重命名：", n, " 个文件"
Call 导出目录树("D:\交付", "D:\交付\目录结构.txt")
```
